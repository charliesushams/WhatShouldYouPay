
# WhatShouldYouPay

# Project Overview

Finding a place to live is a no easy task. This project aims to aid users in their housing search by generating insights into current market conditions and, ultimately, answering the following questions: 

1. Is this rental property fairly priced?
2. What, if anything, most influences the price of a rental property
